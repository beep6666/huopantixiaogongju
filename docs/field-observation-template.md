## L. 给业务负责人核对

- [ ] 时间线是否基本符合实际？
- [ ] 是否遗漏屏幕外的沟通、等待或审批？
- [ ] 哪些现象只是本次偶发？
- [ ] 哪些规则或数据口径被我误解？
- [ ] 哪些材料不能在研究范围外保存？
- [ ] 对发现与解释有何不同意见？

## M. 观察者自检

- [ ] 我有没有提前展示原型并污染基线？
- [ ] 有没有把用户说法或回忆误写成直接观察？
- [ ] 有没有把一次事件推广成普遍结论？
- [ ] 有没有把空值理解为“没有”？
- [ ] 有没有漏记等待和返工时间？
- [ ] 有没有把数据问题和业务冲突混在一起？
- [ ] 有没有替对方提出解决方案？
- [ ] 有没有把前后变化描述成因果？
- [ ] 是否记录了反驳当前产品方向的证据？
